## 第一步：核心主张

**问题：这篇文章，您想让读者读完之后，对什么产生新的理解？**

用您平时说话的语气。

```
我想让读者理解的是：年轻人离开了村子，长辈离开了人世，人和土地之间的牵绊在一点一点消失——说到底，我们参加的每一场葬礼，也是这个村子自己的一部分在消逝。
```

## 第二步：素材召唤

**规则：从大脑里倾倒一切。不组织、不判断、不排序。**

想到什么写什么：经历、对话、用过的工具、读过的书、某个瞬间的感受、一个反例、一句金句。

```
- 葬礼上一个人我不认识，但他死前儿子为了满足他的心愿赶回来结婚
- 他儿子基本没回来过，婚礼和葬礼密集地挤在一起，两种仪式叠在一个人身上
- 我在葬礼上才认识很多亲戚——同姓、同宗，但叫不出名字
- 平时没什么联系的死者兄弟姐妹全部尽力赶回来——不是因为感情好，是因为"这个时候必须到"
- 穿孝服是一种很新奇的体验。
- 年轻人一个个离开村子，长辈一个个离开人世
- 乡村葬礼是村子自己的慢性葬礼
- 看着很失落的感觉
- 没到过年的小镇还是太安静了，哪怕是葬礼也没有多少人。
- 其实想到了乡土中国，但是很可惜之前没有认真读完。现在中国的乡土性也不知道是不是在消失。
- 仪式本质上是赋予生活意义，葬礼的的确确有很多可以优化的陋习，就比如说我一直认为“生者为大”而不是“死者为大”，因为死去的人绝对不会希望因为自己而折磨活下来的人，他们只会希望活下来的人变得更好。但仪式感确实能更加表达思恋、痛苦、在忙碌中消解痛苦、以及传达一些别的情绪，在记忆中铸造新的锚点。
- 我以后也会很难回来，现在这种只见过一面的亲戚可能下次相见很可能会是在他们自己或是别人的葬礼上。又或者说我都不会回来。
```

## 第三步：结构浮现

**流向**：从一段经历开始，慢慢引出观察——但这里的「经历」是一根时间线：走进葬礼现场 → 守夜开始。每一步只往前走一小段，剩下的空间留给插叙。

**结构**：

```
1. 走进小镇 —— 安静、没人、不是过年
   横切：哪怕葬礼也没有多少人
   
2. 走进灵堂 —— 看到一张张不认识的脸
   横切：同姓同宗，叫不出名字 / 平时不联系，死亡一到全部到场

3. 看到那个儿子 —— 两场仪式压在同一个人身上
   横切：赶回来结婚，紧接着父亲去世 / 他几乎没回来过

4. 穿上孝服 —— 新奇感（具体感受待展开）
   横切：布的质感？穿法？周围人看你？身份突然转换？

5. 穿完孝服之后 —— 和几个认识不认识的亲戚打招呼，坐了一会儿
   横切：坐了一天高铁火车汽车才回来——不是刻意回来参加葬礼，只是恰好在我回来之前死了 / 很多人这次其实也没时间回来

6. 去吃夜宵，然后开始守夜
   横切：失落的画面（待具体化）/ 一句念头：「我一直觉得生者为大，不是死者为大——死去的人绝不会希望因为自己折磨活着的人。但坐在这里，穿着这身孝服，又觉得仪式本身在帮活着的人找一个出口。」
   
7. 收束 —— 「我也会很难回来」
   下次见这些只见过一面的人，可能还是葬礼。也可能不会回来。下一次除非是我的爷爷奶奶，我肯定不会回来了。
```

**已决定拿掉的素材**：10（乡土中国——不属于这篇的定位）

**写作姿势**：观察者，不是论述者。插叙不负责讲道理，只负责走到下一个能引发思考的画面。

## 第四步：第一句

我会从这件事开始：坐了一天车回到镇上。

第一句：高铁、火车、汽车，窗外的房子越来越矮，田野越来越多，天也越来越沉。一路换着，像在往时间的上游走。到镇上的时候只剩下路灯亮着，整条街空在那里，安静得不像是在等一场葬礼，像是葬礼已经散场很久了，只是没人来撤灵堂。
